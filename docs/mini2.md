# Мини 2 (`station-mini2`)

Данные контрибьюторов, не перепроверены: PR [#9](https://github.com/Morvex885/pulsar/pull/9)
(ste4ik, прошивка 0.369) и станция из issue [#38](https://github.com/Morvex885/pulsar/issues/38)
(прошивка 0.372; данные — в PR [#43](https://github.com/Morvex885/pulsar/pull/43)). Железо —
[вики](https://hackalice.me/devices/station-mini2/); здесь только то, чего там нет
([AGENTS.md, «Документация»](../AGENTS.md#документация)).

## Userland и хранилище

- Userland armhf, glibc 2.30.
- `/data` → `/bkupgrade/data` (ubifs, свободно ~20 МБ); rootfs заполнен на 83 %.

## Звук

- Захват: `default` (multi из `/etc/asound.conf`), 6 каналов @ 48 кГц: PDM-микрофоны 0–3 из
  `hw:0,1` (каналы 0/2/4/6), петля TDM усилителя 4–5 из `hw:0,0`.
- Воспроизведение: `default` (softvol `Master` над `dmix_spk_plug` → `hw:0,0`); PCM `speakers` нет.
- Громкость: контрол `Master` на `default`; `set_volume.sh` — это `amixer set 'Master' <percent>%`,
  т. е. кривая линейна в процентах.
- VQE: пресет `yandexmini_2`: 4 микрофона, 2 референса, 48 кГц; чанк не записан.
- Спотеры: тот же архив `spotter_models/`, что у Лайт 2; не замерялись.
- alsa-lib 1.2.1.2, неверсионированная —
  [hardware.md, «alsa-lib: версионированная и неверсионированная»](hardware.md#alsa-lib-версионированная-и-неверсионированная).
- В GStreamer прошивки 0.369 нет декодера MP3; стоковые earcons — в `.opus`
  (`common/volume_sound.opus` [inference: наличие файла на станции не подтверждено]).

## Светодиоды и часы

- Часы: по `quasar.cfg` (`/leds/clock`) двоеточие — `PLUS1`+`PLUS2`, `DEGREE` и `MINUS` погашены.
- Часы и датчик освещённости есть не на всех станциях:
  - станция из #9 (0.369): чип часов не проходит probe (`register write to 0x4F failed (error
    -6)`; −6 — ENXIO, чип не ответил на шине), датчика освещённости нет (расходится с вики);
  - станция из #38 (0.372): есть панель (28 сегментов) и датчик `ltr308als01`
    (`in_intensity_input` = raw / 120, без `/etc/light-sensor.conf`).

  [inference: станция из #9 — вариант без часов: по вики, Мини 2 продаётся с часами и без, а часы
  работают и на прошивках 0.369.]

## Кнопки и микрофоны

Данные станции из #9 (0.369).

- Переключателя evdev у отключения микрофонов нет: кнопка не шлёт событий (`sar0_pad0` отдаёт
  только 582/115/114). Состояние — GPIOZ_3 (глобальный 414, подтяжка вверх, активный уровень
  низкий); maind опрашивает этот GPIO.
- Кнопка без фиксации, но схема микрофонов запоминает состояние: пока микрофоны отключены, GPIOZ_3
  читается как 0 и держит этот уровень между нажатиями, так что уровень и есть состояние. GPIOZ_8
  (419) только даёт импульс высокого уровня во время нажатия. Нажатие не обновляет
  `data/is_speaker_muted`, поэтому этот файл как состояние не годится.

## Проверено

- До порта на Rust с C++-демоном из #9: загрузка пресета VQE и захват, wake word → конвейер HA →
  TTS, воспроизведение через 32-битный GStreamer прошивки на `default`, Sendspin с Music
  Assistant, кольцо, сенсорные кнопки, громкость, отключение микрофонов через GPIO и
  `pulsar-install` от начала до конца.
- Rust-демон работал на станции из #38 (0.372, сборка до v0.5.2): часы горят
  (`clock: 28 segments, 2 colon LEDs`), время приходит из HA.

## Не проверено

- Качество спотера.
- Пре-ролл: не замерялся.
- На Rust-демоне: звук, кольцо, кнопки, отключение микрофонов, установка и автозапуск после
  перезагрузки.
- Подстройка яркости часов по датчику: v0.5.2 на Мини 2 не запускалась
  ([#43](https://github.com/Morvex885/pulsar/pull/43)).
