# Ревью WP-05 — плеер (GStreamer) + Mixer, player_probe

- Пакет: WP-05
- Коммит-база: `origin/rust` = `1a6a915` (захват WP-05)
- Ревьюеры: A — «rv05a (баги/паритет)», B + C — «rv05x (архитектура/контракты/unsafe)». Первые ревьюеры B и unsafe остановились на лимите запросов, их заменил rv05x.
- Раунды: 1 — по коммиту `f8176f7`; 2 — по дельте `f8176f7..de3e05a`. Мелкие правки раунда 2 внесены в итоговый коммит.

## Блокирующие

Нет.

## Важные

- [важное] `crates/pulsar-media/src/player.rs` (`Shared::complete`) (A) — C++ проверял `gen` при исполнении колбэка на Loop, поэтому список, закончившийся на потоке GLib перед `stop()`/`play()`, получал `done(false)`; в Rust он получает `Done{ok:true}`. Причина: события идут из рабочего потока прямо в `UnboundedSender`, фильтра на стороне Loop нет — статус: отказ, намеренное отличие. Задокументировано в rustdoc `PlayerEvent::Done`, в контракте `pulsar-media` в ARCHITECTURE.md («список, закончившийся до stop/play, получает ok по факту») и в `wp/WP-12.md` (контроллер сверяет `PlayId` с текущим диалогом/анонсом). «Ровно один Done» сохраняется: тест `list_finished_after_its_replacement_was_requested_is_not_reported_again`.
- [важное] `crates/pulsar-media/src/gst.rs` (`Pipeline::set_str/set_f64/set_i64/set_u32`) (B) — вариадический `g_object_set` с именем свойства от вызывающего: безопасный код мог передать значение не того GType — исправлено (`ed3d40f`): типизированные `set_uri(&CStr)`, `set_volume(f64)`, `set_flags(u32)`, `set_buffer_duration(i64)` с фиксированными именами.

## Мелкие

- [мелкое] `player_probe.rs` — громкость теста всегда 0.2, даже если текущая была ниже, — исправлено: `min(текущая, 0.2)`; при mute (raw 0) воспроизведения нет.
- [мелкое] `player_probe.rs` — потолок 82 был захардкожен — исправлено: `mixer::to_raw(model, 0.2)`.
- [мелкое] `gst.rs` `load_api` — при неудаче уже открытые библиотеки закрывались через dlclose — исправлено: `mem::forget`.
- [мелкое] `gst.rs` `opt` — не проверялся символ со значением NULL — исправлено: адрес резолвится как `*mut c_void`, NULL отвергается, только потом `transmute_copy` (const assert размеров).
- [мелкое] `player.rs` — второй `spawn()` запустил бы второй цикл на контексте по умолчанию — исправлено: `static STARTED`, второй вызов даёт ошибку в логе и деградированный handle.
- [мелкое] `gst.rs` `set_ssl_cert_file` — гонка `set_var` с getenv в других потоках — исправлено: в WP-12 закреплено, что `pulsar_media::spawn()` вызывается до старта других потоков; в ARCHITECTURE п.8 `gst.rs` записан как FFI-модуль, равный `ffi.rs`.
- [мелкое] `gst.rs` `Pipeline` — bus watch не удалялся — исправлено: id сохраняется, `g_source_remove` в `Drop`.
- [мелкое] `AGENTS.md` — Layout и список утилит устарели — исправлено.
- [мелкое] `tests/mixer_golden.rs` — не было сказано, как получены векторы, — исправлено: команда, исходник и строки `rust-port-base`.
- [мелкое] `player.rs` — не было сказано, что паника в машине потока GLib аварийно завершает процесс, — исправлено: комментарий.

Раунд 2:
- [мелкое] `player_probe.rs` `restore()` — при отравленном мьютексе восстановление пропускалось — исправлено в итоговом коммите: `TryLockError::Poisoned(e)` → `e.into_inner()`, пропуск только при `WouldBlock`.
- [мелкое] `player_probe.rs` — лишний `print!("[ts] ")` перед восстановлением — исправлено в итоговом коммите.
- [мелкое] `player.rs` `start` — `STARTED` ставится до dlopen, так что повтор после неудачной загрузки тоже даст деградированный handle — принято: плеер один на процесс, повторной инициализации в C++ не было.
