## Мелкие

Раунд 1 (оба ревьюера), исправлено в `1a84259`:
- [мелкое] `updater.rs` (`install_release`) — у пути бинаря без каталога (`update_probe install … pulsar`) родитель `""`, и `pulsar.new` при запуске `--version` искался в `PATH` — ложная фатальная ошибка — исправлено: пустой родитель = `.` (`binary_dir`), тест.
- [мелкое] `crates/pulsar-update/Cargo.toml` — неиспользуемый `log`; типы pki брались через `rustls::pki_types` — исправлено: `log` убран, импорт напрямую из `rustls_pki_types` (как в ARCHITECTURE: «через rustls-pki-types»).
- [мелкое] `src/bin/update_probe.rs` — `<binary>` проходил через `to_string_lossy` — исправлено: берётся из `args_os` как `PathBuf`.
- [мелкое] `updater.rs` (`run_version`) — запуск свежезаписанного файла мог получить ETXTBSY (fd на запись унаследован ребёнком, форкнутым другим потоком) — исправлено: повтор spawn в пределах 10 с.
- [мелкое] `updater.rs` — отмена (закрытие всех handle) не мешала начать новые шаги после скачивания — исправлено: `Cancel::is_set()` перед заменой, `run_version` в `select!` с `cancel.cancelled()` (уже начатая замена завершается).
- [мелкое] `updater.rs` — при ошибке записи/копирования оставались частичные `pulsar.new`, `<extra>.new`, `pulsar.prev.tmp` (на Lite 2 мало места в `/data`) — исправлено: удаляются.
- [мелкое] `lib.rs` — `pub mod https` вне контракта — исправлено: `#[doc(hidden)]` с комментарием «for update_probe only, not part of the crate's contract».
- [мелкое] `satellite/Makefile` — кросс-clippy вызывал `cargo-zigbuild` напрямую — исправлено: `CARGO_ZIGBUILD ?= cargo-zigbuild`.
- [мелкое] тесты — не было проверки SNI и сервера только с TLS 1.2 — исправлено: тестовый сервер на `LazyConfigAcceptor` пишет SNI и версию; проверены `Some("localhost")`/TLS 1.3 и сервер только с TLS 1.2.
- [мелкое] `AGENTS.md`, `PROGRESS.md` — `make check` теперь требует zig (любой версии) и cargo-zigbuild, «≤ 0.13 отвергается» относится к arch-сборкам; раздел «Updates from HA» ещё про OpenSSL/dlopen — исправлено: строки Build и Host tools, заметка для WP-13 в PROGRESS.

Раунд 2 (оба ревьюера), исправлено в `01bd0e6`:
- [мелкое] семантика отмены отличается от C++: Rust отменяет установку до `--version`/замены при закрытии handle, C++ доводил её до конца; оставшийся `update_attempt` заставил бы автообновление пропускать тег — исправлено: заметка в PROGRESS и пункт в `wp/WP-12.md` «Что обязательно сохранить» (при выходе с установкой в полёте контроллер стирает `update_attempt`).
- [мелкое] `updater.rs` — нет проверки отмены перед `write_file` — исправлено.
- [мелкое] тесты — нет теста отмены после скачивания — исправлено: отмена во время `--version` (скрипт со `sleep 5`) и перед заменой (зависшее extra); после них нет `pulsar.new`, `.prev` не тронут, бинарь прежний, `Installed` не приходит.

Обоснование зависимостей: новых `[workspace.dependencies]` нет; пакет первым использует `ring`, `rustls`, `rustls-pki-types`, `tokio-rustls` (заведены в WP-00). Build-скрипт `ring` компилирует C для цели, поэтому кросс-clippy в `make check` переведён на `cargo-zigbuild clippy` (ARCHITECTURE п.10), job `check` в CI получил zig 0.14.1 и cargo-zigbuild 0.24.0.
