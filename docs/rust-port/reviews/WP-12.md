## Мелкие

Раунд 1, исправлено или задокументировано:
- [мелкое] `controller/mod.rs` (`run`, выход) (B) — при выходе с установкой в полёте `update_attempt` стирался, даже если `Installed{id, Ok}` этой установки уже лежал в очереди (бинарь заменён) — исправлено: перед стиранием очередь `rx.updater` вычерпывается `try_recv`; при `Ok` для этого id `update_attempt` остаётся (его снимет новый бинарь).
- [мелкое] `controller/media.rs` (`set_volume`, `flash_number`) (A) — `volume * 100 + 0.5` без проверки слияния в FMA — проверено: ассемблер C++ `Controller::set_volume` (`zig c++ -std=c++20 -O2`, `aarch64-linux-gnu.2.36` и `arm-linux-gnueabihf.2.30 -mcpu=cortex_a53`) даёт `fmadd s0, s1, s2, s0` и `vfma.f32 s4, s2, s0` перед `fcvtzs`/`vcvt.s32.f32` — исправлено: `mul_add` с комментарием (ARCHITECTURE «Плавающая точка и паритет»).
- [мелкое] `controller/mod.rs` (`Tk`), `voice.rs` (A, B) — таймеры `UiAfterNotSubscribed`/`UiAfterError` (и `CommandsWindow`) — один ключ на назначение, повторный взвод сдвигает срок; в C++ каждый вызов заводил независимый таймер, и `update_ui` срабатывал на первом сроке — задокументировано как намеренное отличие в rustdoc `Tk`: каждое срабатывание выполняет одно и то же идемпотентное обновление, итоговое состояние то же.
- [мелкое] `settings.rs` (`parse`) (A) — значения декодируются lossy UTF-8, C++ хранил сырые байты — задокументировано как принятое отличие в rustdoc `parse`: не-UTF-8 значения не приходят ни от HA, ни из записи демонов.
- [мелкое] `settings.rs` (`save`) (B) — каждое изменение (включая каждое движение слайдера в HA) переписывает `state.conf` без `fsync` перед `rename` — износ ubifs Lite 2 и риск пустого файла при потере питания — как в C++; отложено: строка в «Заметках» PROGRESS — после порта (вне пакета) дебаунс записи 1–2 с с принудительной записью при выходе и перед обновлением, `fsync` перед `rename`.
- [мелкое] `AGENTS.md` Layout (B) — строки про удалённые файлы `satellite/src/*` других пакетов — оставлено для WP-13 (уже записано в «Заметках»); строка контроллера обновлена в этом пакете.

Обоснование зависимостей: новых `[workspace.dependencies]` нет; `pulsar` подключил крейты сервисов (path-зависимости), Cargo.lock обновлён `cargo check`.

Намеренные отличия от C++ (rustdoc, отчёт исполнителя): порт API биндится первым (ошибка — код 1 до запуска железа; до `run` к серверу ничего не доходит), затем `pulsar_media::spawn` до всех сервисов с потоками (`SSL_CERT_FILE`); `_zigbee-coordinator._tcp` уходит в стартовый анонс mDNS; новые строки лога — смещение портов, выход с прерванной установкой, `debug!` причины ошибки Sendspin; UB C++ (`int(float)` и `lround` вне диапазона) в Rust насыщается; неизвестная `MediaCommand` (WP-02: `command: None`) без `debug!`-строки. `esphome_check.py commands` жмёт Zigbee join только с `--zigbee-join`.
