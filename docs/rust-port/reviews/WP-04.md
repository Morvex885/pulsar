## Блокирующие

Нет.

## Важные

- [важное] `crates/pulsar-audio/src/engine/ffi.rs` `Vqe::process` (B) — безопасный API передавал в `YandexVqeC_Process` слайсы произвольной длины; библиотека читает столько, сколько требует пресет, — чтение за границей буфера из safe-кода — `Vqe::new` принимает число mic/spk-каналов модели и хранит ожидаемое число сэмплов (chunk × каналы); `process` при несовпадении или пустом буфере возвращает `Err`, не вызывая библиотеку; `ww_offline` проверяет, что `SPK` задаёт столько каналов, сколько берёт пресет — исправлено в `10fa654`.
- [важное] `crates/pulsar-audio/src/engine/mod.rs` `Engine` (B, также A) — поля освобождались в порядке объявления: VQE раньше спотеров, не как C++ `~Engine` (спотеры → VQE → конфиг) — порядок полей изменён, комментарий объясняет порядок drop; `Vqe::drop` освобождает экземпляр, затем конфиг — исправлено в `10fa654`.

## Проверка на станциях

Обе станции, 2026-10-24, через `station.sh` с lock `WP-04`, сервис остановлен (`stop` … `start`, `cleanup`, `unlock`). Синтетический WAV: «Алиса» через espeak-ng (`-v ru`, 4 варианта скорости/высоты), ресэмпл до частоты модели, речь в mic-каналы, нули в spk-каналы, 8 каналов S16. Эталонный C++ `ww_offline` собран в detached worktree `rust-port-base`. Записи захвата забраны через ssh/cat, в репозиторий не попали.

Midi (раунд 1, бинари до предзагрузки libiconv и флага `--commands`; на Midi `libyandex_evil.so` libiconv не требует):
- `frontend_probe 20 --stream --music --record rec.wav 5` (командный спотер тогда был включён всегда) → `capture hw:0,2: 96000 Hz, 8 ch, period 3072, buffer 16384`, `chunks 31.20/s, audio 31.25/s, music 31.20/s`, `dropped 0`, `processing behind` нет, rc=0; `--wake yandex` → `channels [0<-vqe9,4<-vqe6]`;
- `ww_offline alisa_midi.wav` → `hits=4` (`EVENT_CONFIRMATION_2ND_STAGE phrase=алиса  HIT` ×4); вывод Rust и C++ побайтно совпадает; на записи `rec.wav` — тоже совпадает (`hits=0`).
