## Намеренные отличия от C++

- Неизвестный `TimerEvent` отбрасывается.
- Неизвестная `MediaCommand` превращается в `command: None`.
- NaN в команде света (Light) отвергается.
- Текст Clock ограничивается по декодированным символам, а не по сырым байтам.
- Диагностика отдаётся из кэша (обновляется по таймеру и при смене IP), а не системными вызовами на каждый запрос.
- Пакет ввода, давший больше 256 КиБ ответов, прерывается; остаток разбирается на следующих пробуждениях без чтения сокета (backpressure).
