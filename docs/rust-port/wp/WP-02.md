- **Host-тесты:**
  - golden-байты ListEntities/DeviceInfo/начальных состояний для конфигурации api_selftest — из эталонного дампа C++ с host-сборки (см. ниже);

- **Эталонный дамп C++** — с host-сборки, а не со станции: C++ `api_selftest` анонсирует `_esphomelib._tcp` (`api_server.cpp:472-473`), и HA увидит новое устройство.
  - Собрать в detached worktree `rust-port-base` под x86_64: `zig c++ -std=c++20 -target x86_64-linux-gnu` из `satellite/tools/api_selftest.cpp`, `satellite/src/esphome/api_server.cpp`, `satellite/src/core/log.cpp`, `satellite/src/core/loop.cpp`.
  - `satellite/src/esphome/mdns.cpp` заменить одноразовой заглушкой с пустыми методами `MdnsResponder`.
  - noise-c — из `satellite/third_party/src/noise-c` (после `satellite/third_party/fetch.sh`): исходники `src/protocol/*.c` + `src/crypto/**` через `zig cc`, либо CMake `satellite/third_party` с `ZIG_TARGET=x86_64-linux-gnu`.
