## Крейт и модули

- **Крейт `pulsar-sendspin`.**
  - **Шим** `shim/sendspin_shim.{h,cpp}`: C-ABI над `SendspinClient`, ролями (player, metadata, controller, visualizer), listener'ами и провайдерами (persistence, network).
    - Непрозрачный handle; конфиг-структура; таблица колбэков из указателей на функции + `void *user`.
    - Строки передаются как `const char*` + длина.
    - Каждая точка входа ловит все исключения (`try { … } catch (...)`): раскрутка в Rust — UB.
    - ALSA в C++ не используется.
  - **`build.rs`:**
    - если задан `PULSAR_SS_BUILD`: собирает шим через `cc` (`cpp(true)`, `std("c++20")`, include из `PULSAR_SS_SRC/sendspin-cpp/include` и `PULSAR_SS_SRC/noise-c/include`, define `SENDSPIN_ENABLE_{PLAYER,OPUS,METADATA,CONTROLLER,VISUALIZER}`);
    - линкует статически, в этом порядке: `sendspin`, `noise_c` (оба в `PULSAR_SS_BUILD/sendspin`), `micro_flac` (`_deps/micro_flac-build`), `micro_opus` (`_deps/micro_opus-build`), `micro_ogg_demuxer` (`_deps/micro_opus-build/micro-ogg-demuxer`), `ixwebsocket` (`_deps/ixwebsocket-build`), затем `c++`;
    - выставляет `cargo:rustc-cfg=sendspin_ffi` и `rustc-check-cfg`, `rerun-if-env-changed` для `PULSAR_SS_*`;
    - без `PULSAR_SS_BUILD`: при `PULSAR_REQUIRE_SS=1` — `panic!` с текстом «build via make»; иначе cfg не ставится, `spawn` возвращает `Err("sendspin: built without sendspin-cpp")`.
  - **Rust-сервис:**
    - актор с интервалом 10 мс, вызывает `client.loop()` на потоке рантайма;
    - удержание конца потока 1 с, `group_stopped`, разрыв → немедленный конец;
    - `report_volume` с `lround` и отправкой только при изменении;
    - `transport` синхронно;
    - `yield_to_local` → `leave`;
    - pairing: 6 цифр, вывод в DISPLAY, operator-токен в лог;
    - файл `unpaired_access`;
    - persistence: файл на ключ, 0600, temp + rename + fsync каталога;
    - visualizer 8 групп/65535, loudness, beat;
    - форматы player в порядке C++, visualizer-конфиг C++.
  - **ALSA-sink** на потоке sync-задачи библиотеки через `pulsar-alsa`, 1:1 с C++:
    - протокол request/apply с `try_lock`;
    - ленивое открытие `speakers`, повтор через 1 с;
    - цикл записи с ожиданием до 20 мс и дедлайном `timeout_ms`;
    - `recover` (EINTR/EAGAIN/EPIPE/ESTRPIPE);
    - учёт `discarded`; `notify_audio_played(frames, finish_us)` по `snd_pcm_delay`;
    - duck-рампа 80 мс только для 16 бит;
    - статистика каждые 10 с;
    - sw_params: start_threshold = avail_min = period.

## Публичный контракт

Контракт — раздел `pulsar-sendspin`, включая «Рецепт линковки C++» в [ARCHITECTURE.md](../ARCHITECTURE.md). Сигнатуры не менять; изменения контракта — по правилам PROCESS.md, п. 3.

- **Bin `sendspin_probe [port=18928] [name=pulsar-test] [seconds=120] [state_dir=/tmp/pulsar-test/sendspin]`:** стартует сервис с громкостью 0.2, печатает события.
- **`docs/rust-port/tools/sendspin_server.py`** (aiosendspin уже в `tools/requirements.txt`): сервер подключается к `ws://<станция>:<port>/sendspin`, стримит тон 10 с (FLAC и PCM 48 кГц), меняет громкость и mute, шлёт group state playing/stopped, проверяет controller-команду, принимает visualizer-кадры. Если API aiosendspin этого не позволяет — проверка уходит в чек-лист владельца (Music Assistant) с записью в отчёте, пакет не блокируется.

## Что обязательно сохранить

- **Совместимость файлов:** persistence-файлы в `<state_dir>` (имя файла = ключ, содержимое — сырые байты blob'а) и `unpaired_access` (первый непробельный символ `0` = выкл.) читаются и пишутся так же, как `sendspin_service.cpp:78-103,699-707`. Сопряжение, сделанное C++-демоном, продолжает работать под Rust и обратно.
- **Рецепт линковки C++:** берётся из ARCHITECTURE.md, раздел `pulsar-sendspin`, где его зафиксировал WP-00.
- **Геттеры** (ARCHITECTURE «Модель исполнения» п.2):
  - `streaming()` меняют колбэки начала/конца потока, обновление группы со `stopped` (завершает удерживаемый конец) и разрыв, найденный в `poll()`; удержание 1 с — только для конца без `stopped` (`sendspin_service.cpp:503-505, 565-566, 643-646`). `yield_to_local()` лишь шлёт `client/leave` и синхронно `streaming` не меняет — как C++;
  - `connected()` — живое неблокирующее чтение: `connection_manager_->is_connected()` = `connected_.load(acquire)`, документировано как вызываемое из любого потока. Handle (`!Send` из-за `transport()`) синхронно на потоке рантайма вызывает `is_connected` шима; разделяемого флага и `spawn_blocking` нет.

## Host-тесты (обязательные)

- **Host-тесты (без ffi):**
  - машина удержания конца потока на `tokio::time::pause` (рестарт за 10 мс, stopped до и после конца, разрыв);
  - рампа gain и масштабирование s16;
  - маппинг спектра (n<8, пустые группы);
  - persistence на tmpdir;
  - округление громкости.

- **Станции (обе, `stop`):**

  - `sendspin_probe` стартует и слушает порт;
  - `sendspin_server.py` проигрывает звук (громкость ≤ 0.2), события Stream/Volume/Mute/Music приходят;
  - в логе нет xrun-штормов.
