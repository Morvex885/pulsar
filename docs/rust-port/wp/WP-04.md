## Публичный контракт

Контракт — раздел `pulsar-audio` в [ARCHITECTURE.md](../ARCHITECTURE.md). Сигнатуры не менять; изменения контракта — по правилам PROCESS.md, п. 3.

- **Bins:**
  - `ww_offline` — тот же CLI, `VT`/`SPK` env, тот же вывод; намеренное отличие от C++: `SPK` должен задавать столько каналов, сколько берёт пресет VQE модели (иначе код 2);
  - `frontend_probe [seconds=30] [--wake alisa|yandex] [--stream] [--music] [--commands] [--record <wav> <seconds>]` (`--commands` включает командный спотер; без него — как демон в простое):
    - печатает события и раз в секунду статистику (чанки, аудио-чанки, music-кадры, отставание FIFO);
    - `--record` пишет сырой 8-канальный захват в WAV для `ww_offline`.

## Что обязательно сохранить

- **Сохранить:**
  - потоки reader и processing; FIFO на 1 с; при переполнении удаляются старые данные и пишется `processing behind`;
  - PCM `NONBLOCK`, `wait(200)`, `recover`, повтор открытия через 2 с;
  - period = чанк VQE, buffer = 8×чанк, точная частота;
  - типы каналов `{9,2,9,2,6,6}`; wake-спотер берёт `VQE_OMNI_WITH_GAIN`, командный — `VQE_OMNI`; раскладка каналов спотера (n<8);
  - события 2/5, маска стопа {0,4,7,9}, до 16 событий, debounce 1200 мс;
  - уровень wake: 47 чанков, топ-8, округление до 0.1 дБ;
  - аудио в контроллер — `VQE_OMNI_WITH_GAIN` в s16 через `lrint`;
  - алгоритм спектра 1:1 со всеми константами;
  - `set_model` применяется перед следующим чанком;
  - ошибка старта (dlopen, VQE, спотер, PCM) → лог `microphone front-end failed to start`, handle без событий (деградированный).

## Host-тесты (обязательные)

- **Host-тесты:**
  - golden спектра (синус, тишина, бит-последовательность) из C++;
  - `wake_level_db`; float→s16;
  - де-интерливинг по `mic_channels`/`spk_channels` обеих моделей;
  - политика FIFO;
  - вывод раскладки каналов спотера;
  - фильтр событий и debounce.

## Проверка на станциях

- **Станции (обе, `stop`):**
  - `frontend_probe 20 --stream --music` — частота точная, без `processing behind`, 31.25 аудио-чанка/с, music-кадры идут;
  - синтетический WAV: речь «Алиса» любым TTS агента (например, `espeak-ng -v ru`), ресэмпл в частоту модели, речь в mic-каналы, нули в spk-каналы, 8 каналов S16;
  - `ww_offline` Rust и C++ (собран в detached worktree `rust-port-base`, см. PROCESS.md) на этом WAV дают одинаковый список событий;
  - если ни один не дал HIT — пометить «распознавание голосом — чек-лист владельца» и не блокировать.
