## Крейт и модули

- **Крейт `pulsar-clock`**, модули `clock_fx` (чистый), `font` (шрифты, текст, лица — чистые), `clock` (актор), `light_sensor` (актор с опросом). `pulsar-clock` не зависит от `pulsar-hw`.

## Публичный контракт

Контракт — раздел `pulsar-hw` и `pulsar-clock` в [ARCHITECTURE.md](../ARCHITECTURE.md). Сигнатуры не менять; изменения контракта — по правилам PROCESS.md, п. 3.

- **Bin `hw_probe`** (`pulsar-hw/src/bin/hw_probe.rs`, после влития WP-07): `pulsar-hw` получает зависимость от `pulsar-clock`. Добавляются подкоманды `clock`, `light <seconds>` и `all` — полный сценарий C++ `hw_probe`.

## Что обязательно сохранить

- **Сохранить:**
  - **sysfs:** пути обеих моделей; на Midi `current` чипа через `realpath(<seg>/device/current)` с дедупликацией; aux-сегменты в 0;
  - **уровень и запись:** `lvl = round(255·bri·ambient)` с клампом [2, 255], 0 при bri ≤ 0; запись только при изменении + полная перезапись каждые 20 тиков;
  - **тайминги:** тик 250 мс, шаг анимаций 20 мс, метр 40 мс;
  - **приоритет содержимого:** из C++;
  - **время и таймер:** время через `localtime_r` (TZ); двоеточие по `tv_nsec < 500 мс`; таймер `mm:ss`/`h:mm`, на 00:00 мигание;
  - **шрифты и лица:** таблицы шрифтов (ASCII, кириллица, °, Ё); 17 лиц + Blink + All faces;
  - **текст и коды:** раскладка и скролл текста; пейджинг кода сопряжения; длительности временного слоя;
  - **музыкальные уровни:** диапазон на источник, τ 3000 мс, мин. 0.15, сброс через 10 с, падение 250 мс, цикл 27/3 с;
  - **датчик:** iio `ltr308als01`, `in_intensity_input` или (raw + offset)·scale; первое значение сразу; актор завершается, когда получатель уничтожен;
  - **деградированные часы:** если sysfs не открылся — лог `clock unavailable`, вывод no-op.

## Host-тесты (обязательные)

- **Host-тесты:**
  - golden `clock_fx` (каждая `Anim` на сетке t) из C++;
  - раскладка глифов и текста, позиции скролла;
  - пейджинг кода;
  - формат таймера;
  - математика уровней (`pause`);
  - выбор слоя по приоритету.

## Проверка на станциях

- **Станции (обе, `stop`):**
  - `hw_probe clock`: readback sysfs сегментов для времени, текста `1234`, лица и кода; уровни яркости; на Midi значения `current` чипов;
  - `hw_probe light 10`: lux > 0 при освещении;
  - `hw_probe all` проходит целиком.
