# Bluetooth-режим колонки

Поведение для пользователя — [README, «Bluetooth-режим колонки»](../README.md#bluetooth-режим-колонки).
Режим экспериментальный: доступность программных интерфейсов не означает, что звук и независимые
регуляторы проверены на данной модели и версии прошивки.

Управление из HA использует тот же канал, что и остальные сущности. API без ключа доступен
узлам сети; вне изолированного стенда используйте [Noise PSK](../README.md#шифрование-api).

## Владение аудиовыходом

- BlueZ и BlueALSA остаются службами прошивки. Для входящего A2DP нужны Adapter1 для `hci0`,
  профиль `A2DP-sink` у BlueALSA и её ALSA-плагин. pulsar останавливает только штатный
  `/usr/bin/bluealsa-aplay`, которым управляет `/etc/init.d/S53bluealsa-aplay`. Без проверяемого
  способа вернуть его после остановки и отката аудиовыход не забирается.
- `PULSAR_BT_MANAGED=1` — контракт супервизора и демона. Снимок в `/tmp/pulsar-bt-owner` хранит
  исходные `Pairable`, `Discoverable` и наличие процесса штатного проигрывателя (три `0`/`1`).
  Рестарт того же бинарника сохраняет снимок; перед повторным запуском супервизор пытается закрыть
  `Pairable` и `Discoverable`. При смене бинарника или запуске нового супервизора он сначала
  возвращает штатный вывод через `ctl.sh bt-restore`: предыдущий бинарник может не понимать
  контракт. При ошибке снимок остаётся. Тестовый экземпляр использует отдельный снимок
  и `test-start --bt` с отдельно загруженным `ctl.sh`, см. [протокол станций](stations.md).
- `state.conf` хранит только `bluetooth_enabled=0|1`. Пары остаются у BlueZ, окно не
  переносится через рестарт. `Pairable` и `Discoverable` — флаги адаптера, не доказательство
  допуска к аудио. Запрещённому источнику закрывается только удалённый профиль A2DP Audio Source,
  не всё соединение устройства.
- Вход привязывается к PCM1 `A2DP-sink` / `source` и его Device1, выход использует обычный
  playback PCM модели. `SoftVolume=true` означает, что BlueALSA уже применила громкость к
  сэмплам. В native-режиме используется уровень выбранного `MediaTransport1`, если доступен,
  иначе `PCM1.Volume`; mute-биты по каналам берутся из PCM1. Эти значения не пишутся в ALSA Master.

## Строка статуса

Text sensor «Bluetooth» использует следующие значения; switch отдельно сообщает разрешение:

| Строка | Значение |
|---|---|
| `off` | входящий Bluetooth-звук выключен |
| `ready` | разрешён, нет источника и окно закрыто |
| `discoverable` | открыто окно для новых сопряжений |
| `connected: <имя>` | принят один телефон; возможен суффикс ` (playing)` или ` (paused)` |
| `error: <причина>` | нет рабочего тракта или не удалось выставить флаги адаптера |

Наличие AVRCP MediaPlayer1 не обязательно для воспроизведения. Без игрока действие `bt` не
отправляет команды на угаданный путь.
