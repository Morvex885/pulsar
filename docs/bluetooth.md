# Bluetooth-режим колонки

Колонка принимает телефон как A2DP-источник и играет его музыку; пультом (пауза / следующий)
она выступает у телефона. Стек — штатный, из init-скриптов прошивки: pulsar его не запускает,
не перезапускает и файлов прошивки не трогает. Железо и стек по моделям — в docs моделей
(Мини 2: [mini2.md, «Bluetooth»](mini2.md#bluetooth)); здесь — межкомпонентные контракты.

## Обнаружение и канал управления

- Адаптер — sysfs-узел `/sys/class/bluetooth/hci0` (создаёт `hciattach` из стека прошивки).
  Где узла нет, там нет и сущностей: список сущностей фиксируется на старте демона.
- Весь ввод-вывод — `dbus-send` к `org.bluez` (есть в прошивке): отдельный dbus-крейт не стоит
  четырёх вызовов ([AGENTS.md, «Правила кода»](../AGENTS.md#правила-кода) — про зависимости).
  Состояние режима живёт в bluetoothd, pulsar — только клиент.
- Один `ObjectManager.GetManagedObjects` несёт всё нужное: видимость адаптера, подключённые
  источники и AVRCP-состояние их игрока; опрос раз в пару секунд — телефон может подключиться
  сам, а состояние адаптера меняется и без наших команд. Строку статуса читают потребители
  (автоматизации HA — по префиксам, голосовой мост владельца — для роутинга «паузы»).

## Строка статуса (контракт с Home Assistant и внешними клиентами)

Text sensor «Bluetooth» — одна строка, префиксы значимы:

| Строка | Значение |
|---|---|
| `off` | не видна, источников нет |
| `discoverable` | видна для сопряжения, источников нет |
| `connected: <имя> (<play/pause-состояние>)` | играет внешний источник |
| `discoverable, connected: …` | комбинация |
| `error: …` | `dbus-send` не ответил / bluetoothd недоступен |

До первого опроса строка пуста. Ограничение источника: статус того, чей объект
`org.bluez.MediaPlayer1` первым (обычно один источник и бывает).

## Не делает pulsar

- `DiscoverableTimeout=0` в `main.conf` прошивки — видимость сама не гаснет; политикой
  «выключить, если никто не подключился» владеет пользователь/HA.
- Профиль HFP (`hfp-ag`) включён прошивкой; забирает ли SCO-соединение микрофон — не
  замерено, при подтверждении — отдельная задача.
